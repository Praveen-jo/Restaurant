# Restaurant
dynamically rendering a restaurant homepage

## Deployment to GitHub Pages

This project is deployed to GitHub Pages using the `gh-pages` branch. The built files (`index.html` and `main.js`) are placed at the root of the `gh-pages` branch for GitHub Pages to serve.

### Branch Structure

#### `main` branch (Source/Development)
**Should commit:**
- Source files: `src/` (all `.js`, `.css`, `.html` templates)
- Configuration files: `package.json`, `package-lock.json`, `webpack.config.js`
- Documentation: `README.md`
- Git configuration: `.gitignore`, `.gitattributes`

**Should NOT commit (ignored via `.gitignore`):**
- `node_modules/` - dependencies (install via `npm install`)
- `dist/` - build output (generated by webpack)
- Cache and build artifacts

#### `gh-pages` branch (Deployment/Production)
**Should have:**
- `index.html` at root (required by GitHub Pages)
- `main.js` at root (required by the application)
- Optionally `README.md` (for GitHub repository page)

**Should NOT have:**
- `src/` - source files
- `node_modules/` - dependencies
- `package.json`, `webpack.config.js` - configuration files
- `dist/` folder - unnecessary (built files should be at root)

### Deployment Workflow

To deploy or redeploy the project:

1. Make sure you have all your work committed:
   ```bash
   git status
   ```

2. Switch to gh-pages branch and merge changes from main:
   ```bash
   git checkout gh-pages && git merge main --no-edit
   ```

3. Build the application:
   ```bash
   npx webpack
   ```

4. Copy built files to root and commit:
   ```bash
   Copy-Item dist/index.html index.html -Force
   Copy-Item dist/main.js main.js -Force
   git add index.html main.js
   git commit -m "Deployment commit"
   git push origin gh-pages
   ```

5. Switch back to main branch:
   ```bash
   git checkout main
   ```

**Note:** Ensure GitHub Pages is configured to use the `gh-pages` branch in your repository settings (Settings → Pages → Source branch).
